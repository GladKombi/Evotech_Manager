# Uploads

Ce dossier contient les fichiers envoyes dans l'application.

- `logos/` : logos et images de marque
- `profiles/` : photos de profil des agents, utilisateurs et membres d'equipe
- `projects/` : images liees aux projets
- `documents/` : fichiers administratifs ou pieces jointes
- `temp/` : fichiers temporaires avant validation

Ne jamais executer de code depuis ce dossier.
