# Evotech Africa MVC Enterprise

Starter kit MVC PHP natif pour la gestion intégrée d'Evotech Africa.

## Installation rapide
1. Copier le dossier dans `htdocs` ou `www`.
2. Importer `database/evotech_africa.sql` dans MySQL.
3. Configurer `config/database.php`.
4. Exécuter `composer dump-autoload`.
5. Pointer le navigateur vers `/public`.
